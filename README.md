# Speakeasy

A web application workspace modeled on the TripDeck architecture.

## Structure

- `index.html`: Main HTML entry point.
- `app.js`: Client application orchestration.
- `css/`: Modular CSS stylesheets (`base.css`, `index.css`).
- `js/modules/`: Native ES modules.
- `functions/api/`: Cloudflare Pages Functions serverless endpoints.
- `assets/`: Static assets and media.

## Development

Run the local dev server using Wrangler:

```bash
npm run dev
```
